网页表格采集器

把公开网页里的表格抓下来，去重、导出 CSV / Excel。不执行 JS，不碰登录态。

{% with msgs = get_flashed_messages(with_categories=true) %} {% for cat, msg in msgs %}
{{ msg }}
{% endfor %} {% endwith %}

只支持服务端渲染的 HTML 表格。整页数据靠 JS 加载的站抓不到。

能做什么

  • 自动识别页面里所有 <table>，按数据量排序，主表排第一
  • 表头识别：<thead> 或首行 <th>，都没有就按数据行处理
  • 处理 colspan 造成的列错位，短行补空、长行对齐
  • 整行去重，或按指定列去重（比如只有「姓名」重复就算重复）
  • 多个分页 URL 可以合并成一张表再导出
  • CSV 带 UTF-8 BOM，Excel 直接双击不乱码；xlsx 带表头样式、冻结首行、自动筛选

不能做什么（如实说明）

  • 不执行 JavaScript —— React / Vue 那种前端渲染的页面抓不到数据
  • 不处理登录、验证码、反爬
  • 不自动翻页（分页地址要你自己填）
  • 只抓公开数据，请自行确认对目标站点的抓取是合规的
